## 🌟 Overview

Welcome to the official developer portfolio of **Darshan Rajput** ([@d4rxh](https://github.com/d4rxh)). 

Designed with a responsive **Dual-Mode System** for both developers and casual visitors:
- **Terminal Mode**: Full zsh-style CLI terminal with command autocomplete, history, 6 themes, and interactive tools.
- **GUI Mode**: Smooth-scrolling, mobile-responsive modern card gallery with **"Try Now 🚀"** instant live previews for all pinned projects!

---

## 🚀 Key Features

- **⚡ Dual-Mode Interface**:
  - **Terminal Mode**: Interactive zsh-style shell with autocomplete, history navigation, and rich command outputs.
  - **GUI Mode**: Full-page smooth scrolling with zero viewport clipping, responsive card grid, and prominent action buttons.
- **🔗 Live Demos for All Pinned Projects**:
  - **Try Now 🚀** buttons link directly to deployed live web apps for all pinned repositories!
  - In Terminal: Type `try kawai`, `try anime`, `try siri`, or `try haruno` to launch live demos directly.
- **🎨 6 Dynamic Cyber & Retro Themes**:
  - 🟢 **Matrix Neon** (Classic hacker emerald green)
  - 🌸 **Kawai Sakura** (Cherry blossom pink, matching Kawai & Sakura-Flix)
  - ⚡ **Cyberpunk 2077** (Neon yellow & cyan)
  - 🔮 **Dracula Purple** (Vampire dark violet)
  - ❄️ **Nord Arctic** (Clean Scandinavian blue)
  - 🟠 **Retro CRT Amber** (Phosphor terminal nostalgia)
- **📱 Fully Mobile & Desktop Responsive**:
  - Fixed viewport and scroll height optimization for mobile browsers (`dvh` units).
  - 1-Tap command pills (`help`, `projects`, `try kawai`, `try anime`, `try siri`, `try haruno`, `skills`, `contact`, `gui`) for touchscreens.
- **🌧️ Matrix Digital Rain Canvas**: Interactive falling code stream background tinted to the active theme.
- **📺 Retro CRT Scanline Overlay**: Optional vintage curved scanlines and subtle phosphor flicker.
- **🔊 Web Audio API Sound Synthesizer**: Programmatic mechanical keyboard clicks and terminal execution chimes (with mute toggle).

## 💻 Interactive CLI Commands

| Command | Description |
| :--- | :--- |
| `help` / `?` | Displays all available terminal commands and utilities |
| `projects` / `ls` | Catalog of pinned and showcase projects with direct **Try Now 🚀** links |
| `try [name]` | Opens project live demo directly in a new tab (`try kawai`, `try anime`, etc.) |
| `about` | Full biography, background facts, and focus areas |
| `skills` | Visual proficiency progress meters across languages, frameworks, backend & DevOps |
| `contact` / `socials` | Email, GitHub, and social channels |
| `theme [name]` | Live switches terminal theme (`matrix`, `sakura`, `cyberpunk`, `dracula`, `nord`, `amber`) |
| `matrix` | Toggles the falling code digital rain background |
| `crt` | Toggles retro CRT scanlines overlay |
| `audio` | Toggles keyboard typing clicks and execution sound synthesizer |
| `gui` | Switches between CLI Terminal and Visual Card Portfolio view |
| `banner` / `motd` | Prints Darshan's custom ASCII brand artwork |
| `clear` / `cls` | Clears terminal history and screen |

## 📦 Getting Started

### Prerequisites
- **Node.js** (v18+) or **Bun**

### Installation
```bash
# 1. Clone repository
git clone https://github.com/d4rxh/Portfolio.git
cd Portfolio

# 2. Install dependencies
npm install
# or
bun install

# 3. Start development server
npm run dev
# or
bun dev
```

## ☁️ Deploy on Netlify

This repository is **100% pre-configured for instant deployment on Netlify**:

### Option 1: One-Click Deploy
[![Deploy to Netlify](https://www.netlify.com/img/deploy/button.svg)](https://app.netlify.com/start/deploy?repository=https://github.com/d4rxh/Portfolio)

### Option 2: Connect via Netlify Dashboard
1. Go to [app.netlify.com](https://app.netlify.com/) and click **"Add new site" > "Import an existing project"**.
2. Select GitHub and choose `d4rxh/Portfolio`.
3. Netlify will automatically detect settings from [`netlify.toml`](netlify.toml):
   - **Build command:** `npm run build`
   - **Publish directory:** `dist`
4. Click **Deploy Site** — your portfolio will be live in seconds!
