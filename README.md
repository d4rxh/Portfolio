## 🌟 Overview

Welcome to the interactive developer portfolio of **Darshan Rajput** ([@d4rxh](https://github.com/d4rxh)). 

Designed for both developers and general visitors, this portfolio offers an authentic **Unix CLI terminal experience** paired with a **Modern Visual GUI Mode**. It highlights pinned works, high-performance streaming platforms, AI chatbots, and complete skill proficiencies with interactive controls, themes, and sound effects.

---

## 🚀 Key Features

- **⚡ Dual-Mode Interface**:
  - **Terminal Mode**: Interactive zsh-style shell with autocomplete, history navigation, and rich command outputs.
  - **GUI Mode**: Clean, responsive modern card gallery showcasing projects, technical skill meters, and contact channels.
- **🎨 6 Dynamic Cyber & Retro Themes**:
  - 🟢 **Matrix Neon** (Classic hacker emerald green)
  - 🌸 **Kawai Sakura** (Cherry blossom pink, matching Kawai & Sakura-Flix)
  - ⚡ **Cyberpunk 2077** (Neon yellow & cyan)
  - 🔮 **Dracula Purple** (Vampire dark violet)
  - ❄️ **Nord Arctic** (Clean Scandinavian blue)
  - 🟠 **Retro CRT Amber** (Phosphor terminal nostalgia)
- **🌧️ Matrix Digital Rain Canvas**: Interactive falling katakana & code stream background.
- **📺 Retro CRT Scanline Overlay**: Authentic vintage curved scanlines and subtle screen flicker effects.
- **🔊 Web Audio API Sound Synthesizer**: Programmatic mechanical keyboard clicks and terminal execution chimes (zero audio file assets, 100% self-contained, with mute toggle).
- **📱 Mobile Optimized with 1-Tap Pills**: Quick command chips (`help`, `about`, `projects`, `skills`, `contact`, `theme`, `clear`) allow smartphone visitors to browse without virtual keyboard typing.
- **⌨️ Keyboard Shortcuts**:
  - `Tab`: Auto-complete commands
  - `↑` / `↓`: Browse command history
  - `Ctrl + L`: Instant screen clear
  - `Enter`: Execute command

## 💻 Interactive CLI Commands

| Command | Description |
| :--- | :--- |
| `help` / `?` | Displays all available terminal commands and utilities |
| `about` | Full biography, background facts, and focus areas |
| `projects` / `ls` | Comprehensive catalog of pinned and showcase projects with direct links |
| `skills` | Visual proficiency progress meters across languages, frameworks, backend & DevOps |
| `contact` / `socials` | Email, GitHub, and social channels |
| `theme [name]` | Live switches terminal theme (`matrix`, `sakura`, `cyberpunk`, `dracula`, `nord`, `amber`) |
| `matrix` | Toggles the falling code digital rain background |
| `crt` | Toggles retro CRT scanlines overlay |
| `audio` | Toggles keyboard typing clicks and execution sound synthesizer |
| `gui` | Switches between CLI Terminal and Visual Card Portfolio view |
| `banner` / `motd` | Prints Darshan's custom ASCII brand artwork |
| `whoami` | Shows authenticated visitor session information |
| `date` | Displays current timestamp |
| `history` | Displays previous commands executed in this session |
| `clear` / `cls` | Clears terminal history and screen |

## 📦 Getting Started

### Prerequisites
- **Node.js** (v18+) or **Bun**
- **npm** / **bun** / **yarn** / **pnpm**

### Installation
```bash
# 1. Clone the repository
git clone https://github.com/d4rxh/Portfolio.git
cd Portfolio

# 2. Install dependencies
npm install
# or with bun
bun install

# 3. Start local development server
npm run dev
# or
bun dev
```

Open `http://localhost:5173` in your browser to explore the portfolio.

## ☁️ Deploy on Netlify

This repository is **100% pre-configured for instant deployment on Netlify**:

### Option 1: One-Click Deploy
Click the button below to link your GitHub repository directly to Netlify:

[![Deploy to Netlify](https://www.netlify.com/img/deploy/button.svg)](https://app.netlify.com/start/deploy?repository=https://github.com/d4rxh/Portfolio)

### Option 2: Manual Git Import on Netlify Dashboard
1. Go to your [Netlify Dashboard](https://app.netlify.com/) and click **"Add new site" > "Import an existing project"**.
2. Connect your GitHub account and select `d4rxh/Portfolio`.
3. Netlify will automatically detect settings from the included [`netlify.toml`](netlify.toml):
   - **Build command:** `npm run build`
   - **Publish directory:** `dist`
4. Click **Deploy Site** — Netlify will build and deploy your site with custom domain and SSL in under 60 seconds!
